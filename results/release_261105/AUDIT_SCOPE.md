# 261105 공개본 검증 범위

2026년 11월 5일(한국시간)에 최종 코드로 9개 분석 단계를 재실행했다. 보존 CSV 157개·132,063행과 비교하여 절대·상대 허용오차 1e-10 내 일치를 확인했다. 비교 대상 누락과 추가 CSV는 없었다. 수치는 `independent_audit.json`, 실행 상태는 `run_summary.json`, 단계별 원출력은 `stage_logs/`에 있다.

미국 3계열·2모형은 예측 어댑터를 가져오지 않는 행렬 계산으로 234개 예측을 재검산했다. 최대 절대차는 4.63e-14 이하이다. 공통 요건 30,360회 판정과 개별/배치 판정 30개를 확인했다. `transfer_numerical_audit.json`을 따른다.

`source_inventory.json`은 실행 시작 시 코드·원자료·지원파일 목록이다. 원자료·지원파일과 9개 실행 진입점은 실행 후에도 해시가 일치한다. 후속 독립 검산 코드의 선택적 문서 검사에서 고정 표 개수를 없앤 변경은 `execution_source_check.json`에 구분했으며, 실제 후속 검산 코드 해시는 독립 검사 보고서에 기록했다.

첫 시도는 코드 서식 변경이 실행과 겹쳐 실행 중 코드 동일성 검사에서 중단됐다. 그 결과를 최종 통과 기록으로 사용하지 않았다. 이후 편집을 마친 9단계 전체를 새 폴더에서 실행했다. `execution_attempts.json`은 이 구분을 기록한다.

이번 작업에서 원자료를 새 기관 통계로 교체하지 않았다. `preserved_audit`는 보완모형의 보존 입력·모형·예측 검산이며 모든 보완모형의 신규 적합을 뜻하지 않는다. 자료의 진위·과거 최초 공표판본을 인증하거나 실제 현장효과를 추정한 것은 아니다. 현장 참여자·응답은 0건이며 계획과 빈 양식만 제공한다.

옛 문서와 편집·검증 중간자료 76개를 현재 파일 목록에서 제거했다. 정확한 경로와 프로토콜 설명 문구의 전후 해시는 `cleanup_record.json`에 있다. 과거 실행기록의 프로토콜 해시는 원래 기록을 보존한다. 코드·입력·표·그림의 현재 배포 해시는 루트 manifest를 따른다.
