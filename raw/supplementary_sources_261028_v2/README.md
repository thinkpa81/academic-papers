# 누락 원자료와 공표일 근거의 복원

2026년 10월 28일 기존 보존 재현패키지에서 원본 바이트를 그대로 복원하였다. 원본 Drive 파일·ZIP 해시·ZIP 내부 경로·파일별 SHA-256 및 SHA-512는 `restoration_manifest.json`에 기록하였다. 기존 분석 입력은 변경하지 않았다.

- `source_release/`: 2013–2025년 보도자료 HTML, PDF 추출 텍스트, 공표일·관측주간 목록 및 출처·해시 명세. PDF 원파일은 포함되어 있지 않으며 공식 URL과 당시 해시만 보존되어 있다.
- `source_employment/`: KOSIS 구분류 S 통계표의 대조용 DOM, OECD 고용 v2.4 응답 및 반기·판본 대조 자료.
- `source_covariates/`: OECD 노동지표 v2.4의 요청·응답·실패와 재시도 로그, 정규화 및 판본 간 중첩 대조.

이 복원은 당시 확보기록의 보존·추적을 보완한다. 당시 원자료의 실시간 최초 공표판본 또는 기관 내부 생성과정을 새로 검증한 것은 아니다.
