# 문체와 방법 서술 검토

이 검토는 특정 낱말이 KCI 전체에서 금지된다는 판정이 아니다. 논문의 자료, 분석 절차, 기술평가 범위가 독자에게 정확히 전달되는지를 기준으로 수정안을 제시하였다. 실제 투고에서는 한국IT서비스학회의 편집방침과 투고요령을 적용한다. 원문 전체를 새로운 연구로 재작성하거나 수치를 변경하지 않았다.

## 요청별 판정

| 번호 | 검토 대상 | 판단 및 수정 방향 |
|---|---|---|
| 1 | 본 연구의 구체화와 평가 위치 | 뜻은 통하지만 추상적이다. 표의 내용은 선행지식의 적용과 관련 본문 절이므로 ‘본 연구의 적용 내용과 관련 절’이 정확하다. |
| 2 | 회고적 예측성능과 구현 기능의 작동 | 회고적은 사용 가능한 말이다. 다만 개정자료 기반의 시간순 평가라는 구체적 설계가 보이지 않는다. ‘개정자료를 이용한 과거기간 예측성능과 서비스 기능의 요구사항 충족 여부’로 수정한다. |
| 3 | 평가 및 점검 내용 | 잘못된 표현은 아니나 의미가 중복된다. ‘평가 항목 및 방법’으로 정리한다. |
| 4 | 그림 1 화살표 | 문체 문제가 아니라 실제 연결관계 문제이다. 그림 검증 담당의 수치·연결 확인 결과를 적용한다. |
| 5 | 주분석은 … 회고적 평가 | ‘2026년 9월 확보한 개정자료를 시간순으로 분할하여 과거기간의 예측성능을 평가한 것’으로 설명한다. 과거 공표 당시 이용 가능한 자료로 수행한 실시간 검증과 구분한다. |
| 6 | 확장창 | expanding window의 번역으로 이해할 수 있으나 최초 정의가 부록에 있고 본문에서 먼저 반복된다. 본문 첫 등장에 ‘학습기간 확장 방식(expanding-window evaluation)’으로 정의하고 이후 명칭을 통일한다. 6개 창은 6회 평가로 표기한다. |
| 7 | v1, v2, v3 | 소프트웨어·검사 명세 버전으로 정의하면 사용할 수 있다. 최초 등장에 버전 1(v1)~버전 3(v3)을 정의한다. 코드·원자료 식별자는 유지한다. |
| 8 | 실질 GDP·소비·투자 | 포괄적 약칭이어서 실제 변수 범위가 불명확하다. 공식 macrodata 정의에 따라 실질 국내총생산, 실질 개인소비지출, 실질 민간국내총투자로 구체화한다. |
| 9 | SHA-256 대신 SHA-512 | SHA-512도 가능하다. 다만 본문 이름만 바꾸면 재현기록과 불일치한다. 과거 SHA-256 참조와 서비스 연결키는 유지하고 신규 배포목록에 SHA-512를 추가하는 방식이 적절하다. |
| 10 | 절편 축소와 소지역 추정 | 문체보다 규제 대상이 모호한 것이 문제이다. 실제 코드는 공통 절편·기울기를 규제하지 않고 시도·산업의 절편 편차에만 L₂ 규제를 적용한다. 인용 문헌의 Fay–Herriot 모형과 입력정보·추정 목적을 구분한다. |
| 11 | 그림 2 | 실제 값과 설명·절차의 일치를 확인해야 한다. 그림 검증 담당의 확인 결과를 적용한다. |
| 12 | 그림 3 | 예측편차는 고용 증감 자체가 아니다. 부분집계·미산출 및 검증사례 수가 구별되어야 한다. 그림 검증 결과를 적용한다. |
| 13 | 해석 범위 | 학술 문체로 적합하다. 해당 표에서는 ‘결과의 해석 범위’가 조금 더 명료하다. |
| 14 | 소급보정·신분류 공표 이력은 메타데이터 | 적합하지만 ‘소급보정 범위와 개정 산업분류의 공표 이력은 자료의 작성 및 변경 과정을 설명하는 메타데이터’로 구체화한다. |
| 15 | IS에서 식별자로 기록 연결 | 기존 정보시스템 일반의 사실인지 저자의 설계 제안인지 불분명하다. PROV[56,57]의 관계 기록 원리를 근거로 두고 구체적 식별자 구조는 ‘본 연구가 제안하는 기관 적용 방안’으로 명시한다. |
| 16 | 6.2와 6.3 자기비판 | 현재 근거의 적용조건과 미평가 영역을 공개하는 것은 필요하다. 한계를 삭제하지 않고 6.2는 성취와 적용범위를 먼저 제시하며, 6.3은 이미 준비한 과업·프로그램과 후속 실증계획 중심으로 정리한다. |
| 17 | DT_1ES3B05S | 통계표 ID이므로 원형 표기가 적합하다. 대소문자와 밑줄을 유지하고 처음에 통계표 ID임을 알린다. |
| 18 | 절대 허용 오차 10⁻⁹ | 과학적 표기로 적합하다. 필요하면 절대차 \|a−b\|≤10⁻⁹라는 판정식을 명시한다. 통계적 유의수준이나 상대오차와 혼동하지 않게 한다. |
| 19 | 참여자 0, not_evaluated, 재현파일 | 실제 관측이 없음을 밝히는 것은 필수이다. ‘아직 자료수집을 실시하지 않았으며 빈 자료의 분석 상태값은 not_evaluated’로 자연스럽게 쓸 수 있다. 경로는 GitHub 기준 커밋의 파일과 동봉 수정본을 구분한다. .gz는 gzip 무손실 압축으로 설명하며 압축파일 자체와 해제 내용의 해시는 구분한다. |

## 추가로 발견한 실질 문제

3.5절의 ‘구성산업 RSE 25% 이상 표시’에 붙은 [27]은 Fay–Herriot 소지역 추정 논문이어서 해당 경고 기준의 출처가 될 수 없다. 주 검토자가 원자료 [5]에서 해당 표시를 확인하여 [5]로 교체하기로 하였다.

부록 G의 ‘최초 확보일은 2009년 12월 15일’은 연구자의 자료 확보일로 읽힐 수 있다. 공식 제공 문서의 해당 날짜는 데이터 편집자가 FRED·BLS 출처에 접근한 날짜이므로 주체를 명시하도록 수정하였다.

## 확인 근거

- statsmodels 공식 데이터 설명: https://www.statsmodels.org/stable/datasets/generated/macrodata.html — 203분기, realgdp·realcons·realinv 정의, 2005년 연쇄가격, 계절조정 연율 수준 및 편집자의 출처 접근일.
- 패키지 보존 문서: raw/transfer_macrodata/source_description.py — 위 정의와 동일.
- 실제 절편 축소 구현: support/forecast_addendum/run_addendum.py, PanelShrinkage — 공통 절편·기울기의 벌점은 0이고 시도·산업 범주 계수에만 λ 적용.
- 학회 투고자 매뉴얼: https://www.itservice.or.kr/download/manual.pdf — 편집방침과 투고요령에 따라 작성하도록 안내.

본문 37문단과 표 5셀의 수정안은 prose_recommendations.json에 원문·수정문·이유와 함께 수록하였다. 수정 전 텍스트와 인덱스가 실제 DOCX와 모두 일치함을 확인하였다. 그림·인용·공개경로의 최종 결과는 각 담당 검토 결과와 통합해야 한다.
