157개 CSV 중 156개는 저장 바이트까지 동일하다. 나머지 `case_results.csv`는 보존본이 gzip 압축되어 파일 바이트가 다르지만, 압축 해제 후 내용은 동일하다. 대조의 수치 허용오차는 상대·절대 각각 1e-10으로 지정하였으나, 이 비교에서는 압축 형식 차이를 제외한 파일 내용도 일치하였다.

추가 독립 검사는 분석 함수의 특징 생성 코드를 호출하지 않고 보존된 정규화 원자료에서 1,449행의 목표변수와 입력변수 7개를 직접 계산하였다. 입력연도·지역경계 제외·타지역 집계 식별자도 대조하였다. 수정 전 `261028_v2` 논문의 연구표 24개, 780개 셀이 표 CSV와 일치하는지 확인하였다. 최종 `v3` 문서의 어휘·표기 및 학회 양식 검증은 별도의 문서 검증 범위이다.

최종 `261028_v3` 원고의 표도 추가 대조하였다(`final_manuscript_table_audit.json`). 연구표 24개·780개 셀 중 28개 셀의 표시가 달랐다. 27개는 마이너스·대시 문자를 ASCII 하이픈으로 바꾼 차이이며, 나머지 1개는 표 1의 문헌명과 인용번호 사이에 넣은 줄바꿈이다. 비교에서는 세 문자(U+2212, U+2013, U+2014)를 하이픈으로 통일하고 배치를 위한 공백·줄바꿈만 제거하였다. 이 범위에서 모든 셀이 일치했고, 실제 변경 전후 문자열을 셀별로 기록하여 숫자·문구의 변경이 없음을 확인하였다. 원자료·통계 결과 CSV는 수정하지 않았다. 보고서에는 검토한 DOCX의 파일 크기와 SHA-256도 기록하였다.

## 실행 범위의 한계

9개 단계에는 원자료 정규화와 주분석 적합, 38개 후보의 고정분할·6회 학습기간 확장 평가, 1,000회 시도 군집 재선정, 지역 제외 평가, 서비스·모형 교체·등록 근거·공통 요건 시험이 포함된다. `preserved_audit` 단계는 OECD 원계열·2024년 고정 모형·통합지역의 보존된 예측·모형·입력을 검산한다. 따라서 9개 단계 완료를 모든 보완모형의 신규 재학습이라고 해석하지 않는다.

현재 개정자료의 시간순 분할을 과거 최초 공표판본의 실시간 예측성능으로 해석할 수 없다. 학습기간 확장 및 후보군 추가는 기존 평가결과를 확인한 뒤 수행한 탐색적 분석이다. 시도 군집 구간은 관측된 기간과 지정된 후보군에 조건부이며 시도 간 공통 충격, 모든 후보군의 사후 선택 및 원자료 개정 전체를 보정하지 않는다.

기술시험 입력은 같은 기반 예측에서 파생한 합성 사례이다. 수용·차단 횟수는 독립 참여자 수나 현장 오류율이 아니다. 실제 담당자 판단, 검토시간, 조직성과 개선은 검증하지 않았다. 파일 해시는 동일성 검사이며 원기관 자료의 진위나 과거 확보시점의 외부 인증이 아니다. 참고문헌과 정책·통계 공표 내용의 웹 검증은 별도 출처 검토 기록을 참조한다.

## 코드 및 환경

주요 버전과 실행 스레드 제어는 `environment_final.json`에 기록하였다. 설치가 필요했던 의존성은 격리한 임시 경로에 설치하였고 설치 로그를 보존하였다. 설치된 바이너리·임시 환경 자체는 재현패키지에 포함하지 않았다. `requirements.txt`를 사용하는 일반 설치에서는 하위 의존성도 함께 설치된다.

`analysis_code_sha256.json`은 주요 분석 코드의 재실행 후 식별자를 기록하며, 최종 원고의 표시 정규화 검사를 보완한 `v3_independent_audit.py`의 해시와 갱신시각도 포함한다. 이 후속 감사 코드 수정은 모형 적합이나 예측값을 변경하지 않았다. 네 개 전이시험 모듈은 적합 및 평가 전 해시와 실행 종료 시 동일성도 확인하였다(`transfer_protocol_before_execution.json`, `transfer_execution_start.json`). 이 기록은 연구진 내부 실행 기록이며 외부 사전등록이나 독립 평가를 의미하지 않는다.

새로운 재실행은 패키지 루트에서 다음과 같이 수행한다.

```bash
python code/run_all.py --out ../rerun_261028_v3
python code/verify_results.py --report ../result_checks_261028_v3.json
python -m unittest discover -s tests -v
python code/v3_independent_audit.py --out ../independent_audit_261028_v3.json --replay ../rerun_261028_v3
python code/audit_transfer_results.py --source ../rerun_261028_v3/transfer_evaluation
```

마지막 명령은 새 출력의 `numerical_audit.json`만 작성한다. 기존 결과 폴더를 지정하지 않아 보존 기록을 유지한다. 최종 원고의 표를 대조하려면 `v3_independent_audit.py`에 `--manuscript <검토할 DOCX>`를 추가한다. 이 검사는 결과표의 텍스트와 CSV의 대응을 확인하며 시각적 배치 검토를 대체하지 않는다.
