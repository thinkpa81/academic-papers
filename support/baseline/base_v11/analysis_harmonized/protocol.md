# 정합화 지역고용 분석 재실행 명세

문서 복구일: 2026-11-05(한국시간)

## 문서의 범위와 이력

이 문서는 `run.py`와 보존된 선정·평가 기록에서 확인한 분석 절차를 명시한다. 배포본에 빠져 있던 실행 의존성을 복구하기 위해 작성하였다. 기존 프로토콜의 원문 바이트는 확보하지 못했으므로 과거 문서와 동일한 파일이거나 당시의 사전등록 문서라고 주장하지 않는다.

과거 `results/main/selection_before_test.json`에 기록된 프로토콜 SHA-256은 `cef372ff8069a38b3de6c27489a28692f50cdc8d7ed0df85c7eb177a9fb7e35f`이다. 이 역사적 기록은 유지한다. 새 재적합에서는 이 파일의 실제 SHA-256이 새로운 `selection_before_test.json`에 기록된다. 복구 경위와 재실행 결과는 저장소 최상위의 `results/release_261105/protocol_restoration/`에서 확인한다.

## 입력과 분석단위

- 입력: `support/baseline/base_v11/source_harmonized/kosis_ksic11_H1_2013_2025_panel.csv`.
- 자료: 확보된 제11차 산업분류 기준 개정계열, 2013-2025년 상반기 취업자 수. 현재 판본의 후향적 평가로 사용한다.
- 기본 단위: 17개 시도와 10개 산업군(A, BTE, F, GTI, J, K, L, M_N, OTQ, RTU). 공식 전체 취업자 수 `_T`는 비중과 지역 전체 변동의 분모이다.
- 구성산업이 완전하게 관측된 합계만 사용한다. 결측값을 0으로 대체하지 않는다. 중복된 지역-연도-산업 식별자는 오류로 처리한다.

## 목표값과 입력변수

목표연도 Y의 목표값은 `100 * log(E[Y] / E[Y-1])`이다. 수치형 입력은 이전 시점 고용규모의 자연로그, 공식 지역 총계 대비 산업 고용비중, 최근 고용변동, 그 이전 변동, 가용 타 시도의 같은 산업 합산 고용변동, 지역 전체 고용변동의 여섯 가지다. 지역과 산업은 범주형 입력이다.

자기 지역의 Y부터 Y-3까지 고용과 Y-1·Y-2년 공식 지역 총계가 유한한 양수여야 한다. 타 지역 합산은 해당 비교에 필요한 두 시점이 모두 존재하는 동일 지역 집합을 사용한다. 입력에 목표연도의 결과를 사용하지 않는다.

기본 경계 제외 설정은 충남 2017년, 대구·경북 2024년 전환이다. 목표연도 Y, Y-1 또는 Y-2에 지정 전환이 포함되면 해당 분석행을 제외한다. 타 지역 합산에는 입력 전환의 적격성을 별도로 적용한다. 실제 제외 사유와 가용 지역 집합은 `exclusion_ledger.csv`와 `analysis_panel.csv`에 남긴다. 경계 제외를 해제한 민감도 분석은 기본 분석과 구분하여 저장한다.

## 기간 분할과 전처리

| 구간 | 목표연도 | 용도 |
| --- | --- | --- |
| 훈련 | 2016-2019 | 검증용 전처리·모형 적합 |
| 검증 | 2020-2022 | 비가중 MAE에 따른 후보 선정 |
| 평가 | 2023-2025 | 선정 완료 후 성능 평가 |

수치형 변수는 StandardScaler로 표준화하고, 범주형 변수는 미지 범주를 허용하는 원핫 인코딩을 적용한다. 검증용 변환은 훈련자료에서만 적합한다. 선정 후 훈련·검증자료를 합쳐 변환과 모형을 다시 적합하고 평가기간에는 고정한다.

## 비교 후보와 선정

기준모형 여섯 가지는 수준 유지(로그변동 0), 최근 변동 지속, 산업별 과거평균, 전체 과거평균, 전체 과거중앙값, 가용 시도의 산업별 합산 고용에 대한 직전기 로그변동이다.

| 학습모형 | 후보 설정 |
| --- | --- |
| 릿지 | alpha: 1, 10, 100, 1000, 10000 |
| 랜덤포레스트 | 나무 300개; max_depth: 4, 8; min_samples_leaf: 10, 25; n_jobs: 1 |
| 히스토그램 그래디언트 부스팅 | max_iter: 200; learning_rate: 0.05; max_leaf_nodes: 7, 15; l2_regularization: 1, 10; min_samples_leaf: 20; early_stopping: False |
| 후버 | epsilon: 1.35; alpha: 0.0001; max_iter: 2000; tol: 0.000001 |

기준모형 6개와 학습모형 14개 설정을 검증한다. 난수 시드는 `20260926`이다. 검증 MAE의 안정 정렬로 최선 기준모형, 최선 학습모형 및 각 학습모형군의 설정을 선정한다. 기본 제시값은 선정된 기준모형이며 자동 승격을 적용하지 않는다. 평가 대상은 모든 기준모형, 학습모형군별 선정 설정과 `ridge_alpha100` 비교 설정의 중복 없는 합집합이다. 평가 결과로 후보 설정을 다시 선택하지 않는다.

## 평가와 불확실성

평균절대오차, 평균제곱근오차, 입력시점 고용규모 가중 평균절대오차, 결정계수, 변동 부호 일치율 및 비음수 이진 방향 일치율을 산출한다. 전체 및 연도별 결과, 입력 고용 1만 명 이상·미만의 결과를 구분한다. 방향 지표의 영점 기준은 코드의 부호 함수 정의를 따른다.

시도별 산업·평가연도 관측을 함께 추출하는 군집 부트스트랩을 2,000회 수행한다. 고정한 예측에서 기준모형 대비 MAE 차이를 계산하고 2.5·97.5백분위수를 보고한다. 이 구간은 관측연도와 적합된 모형에 조건부이며, 부트스트랩 안에서 모형을 재선정하거나 재적합하지 않는다.

선형모형 계수와 훈련·검증자료에서 적합된 변환을 보존한다. 권역-산업별 사전 비교정보는 훈련자료로 적합한 검증 예측에서 계산하여 평가 결과와 구분한다. 경고·선정·표본·모형·예측·지표·구간은 각 출력 디렉터리에 기록한다.

## 대구·경북 통합지역 분석의 적용

`extensions/revision_v8/region/run_region_d.py`는 대구와 경북의 고용 및 공식 총계를 먼저 합산하여 16개 고정 지역 단위를 구성한다. 두 지역 값이 모두 관측되는 합계만 사용한 후 목표값과 입력을 다시 계산한다. 대구·경북 내부 경계 이동의 제외는 적용하지 않고 충남 2017년 전환 제외는 유지한다.

위 기간·후보·전처리·검증 선정 절차를 재사용하며, 별도의 `protocol_before_execution.json`에 통합 규칙과 실행정보를 남긴다. 새 선정기록에는 이 문서의 해시와 통합지역 실행 프로토콜의 해시를 함께 기록한다. 통합지역 결과는 원래 17개 시도 분석과 구분하고, 두 분석의 차이를 경계 보정의 인과효과로 해석하지 않는다.

## 실행과 결과 대조

저장소 최상위를 작업 폴더로 하고 Python 3.12 및 `requirements.txt`의 버전을 사용한다. 기존 보존 결과를 덮어쓰지 않는 새 출력 경로를 지정한다.

```bash
python support/baseline/base_v11/extensions/revision_v8/region/run_region_d.py --package-root support/baseline/base_v11 --output-dir ../rerun_merged_region
```

선정과 평가를 완료한 뒤 입력·코드·프로토콜의 해시, 선정 설정, 표본 수, 예측과 지표를 확인한다. 보존 CSV와의 수치 대조에는 절대·상대 허용오차 각각 `1e-10`을 사용한다. 실행시각과 새 프로토콜 해시 등 판본에 따라 변하는 메타데이터는 과거 실행기록과 별도로 보존한다. 해시는 파일 동일성을 확인하는 수단이며 과거 확보시점의 인증은 아니다.
