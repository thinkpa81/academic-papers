# 지역고용 예측근거 검토 예비평가 실행계획

2026년 10월 28일 개정. 실제 참여자 0명, 관측 0건. 과거의 12명·12과업·4조건 계획은 아래의 8명·16과업·2조건 계획으로 대체한다. 연구 결과에는 실시 계획과 실제 결과를 구분하여 기술한다.

## 목적과 범위

표와 카드가 같은 정보를 제시할 때 연구용 검토 판단의 정확도와 시간을 비교한다. 이 예비평가는 화면 구성의 사용성을 점검한다. 전체 DSS 도입의 인과효과, 실제 정책 판단의 정확도와 기관 성과는 평가 범위가 아니다. 경고·차단 개입은 두 조건 모두 최초 판단 이후에도 표시하지 않아 정답 학습과 기계 개입을 분리한다.

## 참여자와 배정

지역인적자원개발위원회, 지방자치단체 또는 유관기관에서 인력·훈련 수급이나 지역고용 자료 검토 경험이 있는 실제 담당자 8명을 계획한다. 직무와 경력은 비식별 범주로 별도 기록한다. 계획 코드 P01~P08을 참여 순서와 독립적으로 무작위 배정하고 배정기록을 보존한다. 8명은 실행 가능성을 점검하는 예비규모이며 확증평가의 검정력을 보장하지 않는다. 인원을 바꿀 때는 관측 전 배정표를 다시 고정하고 변경사유를 남긴다.

각 참여자는 서로 다른 16개 과업을 한 번씩 수행한다. 표 8개와 카드 8개를 보며, 정상·이전 판본·검증사례 수 불일치·모형계수 불일치의 네 유형이 조건별로 각각 2개씩 포함된다. 전체 계획에서 각 과업은 표와 카드에 각각 4회 배정된다. 과업 순서는 고정 난수시드로 무작위화한다. 반복행 128개는 독립 표본 128명이 아니다.

## 과업과 정보 통제

과업의 기준·릿지 예측값, 검증사례 수와 계수는 보존된 실제 2025년 예측에서 가져온다. 검토 판본 R01·R02와 결함은 평가용으로 구성한다. 고용결과나 참여자 판단을 생성하지 않는다. task_provenance.json에 원사례 식별자와 변경내용을 기록한다. 표와 카드는 동일 JSON의 동일 17개 항목을 표시한다. 정답을 직접 알려 주는 결함 유형명은 참여자 화면에 제시하지 않는다. 원자료의 결측과 0개 검증사례는 그 자체로 연구용 검토를 차단하는 정답이 아니다. 정답은 제시된 판본·사례 수·계수의 일치 요건으로 판정하며 실제 정책 정답과 구분한다.

## 실시 절차

1. 연구책임자가 소속기관의 연구윤리 검토 절차에 따라 실시 조건을 확인하고 연구 안내·동의 및 자료보관 방식을 확정한다. 기관 판단 결과를 실제 기록으로 보존한다.
2. 참여자에게 목적, 중단·철회 방법, 비식별 기록항목과 보관기간을 안내한다. 이 참여는 인사평가에 사용하지 않는다.
3. 본 과업과 다른 가상 예시로 판본·사례 수·계수의 일치 조건을 설명한다. 안내시간은 판단시간에 포함하지 않는다.
4. 진행자가 아래 명령으로 로컬 프로그램을 실행하고 같은 컴퓨터에서 참여자 코드를 입력한다. 화면 크기·확대율·기기와 진행자 설명을 조건 간 동일하게 유지한다.
5. 과업 시작부터 최초 판단 제출까지 서버가 경과시간을 측정한다. 최초 판단을 별도 기록한 후 근거 문장, 판단 확신도와 근거 신뢰성 문항을 받는다. 그 작성시간은 판단시간에서 제외한다. 과업별 정답 피드백은 제공하지 않는다.
6. 두 평가자가 조건을 가린 기록에 대해 핵심 근거와 후속 조치를 각각 1점, 합계 0~2점으로 채점한다. 개별 원점수·불일치·조정 결과를 보존한다. ratings_EMPTY.csv는 두 평가자 원점수 기록양식이다.
7. 종료 후 이해하기 어려운 항목과 실제 업무 적용조건을 면담한다. 인용은 동의 범위에서 익명화한다.

## 지표와 분석

일차 지표는 최초 판단 정답률이다. 참가자별 조건당 정답 수/8로 계산한다. 이차 지표는 참여자별 판단시간 중앙값, 결함 입력 허용률(분모 조건당 6개), 정상 입력 보류율(분모 조건당 2개), 근거 서술 점수와 판단 확신도이다. 근거 신뢰성 1~7점은 탐색적 단일 문항이며 검증된 신뢰 척도로 명명하지 않는다. 신뢰는 정상·결함 유형별로 구분하여 해석한다. 일률적인 상승을 성공으로 판단하지 않는다.

참여자별 카드−표의 차이를 먼저 계산한다. 소표본 예비평가에서는 분포와 원자료, 평균·중앙값을 기술하며 과업행을 독립 표본으로 취급한 유의확률을 산출하지 않는다. 중도탈락 기록은 기술통계에 남기고 16개 과업을 완료한 참여자만 조건 차이에 포함한다. 판단 후 설명을 중단한 사례는 judgments.jsonl로 확인하여 누락·중단 현황에 따로 기록한다. 임의 대체와 성과에 따른 이상값 제거를 적용하지 않는다.

후속 확증평가는 예비자료의 참여자 내 변동과 과업 난이도에 근거해 표본수를 설계하고, 일차 가설·최소 실무적 차이·제외기준·다중비교·결측 처리와 분석모형을 관측 전에 확정한다. 결과가 유리한 조건만 논문에 추가하지 않는다.

## 실행과 기록

Python 3.12에서 재현패키지 폴더를 연다.

```bash
python code/collect_field_study.py --records ../private_field_records
```

동일 컴퓨터에서 http://127.0.0.1:8765 를 열어 한 명씩 실시한다. 응답은 지정 폴더의 responses.csv와 judgments.jsonl에 저장한다. 이 프로그램은 서버 재시작 시 진행 중 과업을 복구하지 않으므로 중단 시 해당 최초 판단 로그를 보존하고 재노출 여부를 절차 이탈로 기록한다. 수집자료 폴더는 공개 저장소에 넣지 않는다.

```bash
python code/analyze_field_study.py --responses ../private_field_records/responses.csv --out ../pilot_results
```

출력 폴더는 새 경로여야 한다. 빈 양식은 not_evaluated 상태만 산출한다. 실제 관측을 human_observed로 기록한 입력만 분석하며, 이 표시는 연구자가 원기록을 확인하여 유지할 기록 구분이다. 코드가 참여자의 실제 존재를 인증하는 것은 아니다. 시스템 시험자료는 임시 폴더에서만 사용하고 연구자료에 합치지 않는다.

## 일정과 책임

준비 1일: 연구책임자가 안내·동의·배정표와 과업 내용을 확정한다. 실시 2~4일: 현장 진행자가 8명의 일정과 기기 조건을 관리한다. 채점 1~2일: 두 평가자가 독립 채점한다. 분석·원고 반영 1일: 분석 담당자가 원기록, 누락과 참여자별 비교를 확인하고 실제 관측에 근거해 결과를 작성한다. 일정은 참여자 모집과 기관 검토 완료 이후의 계획이다.
